# Linux 服务器常用命令笔记

> 适合刚接触 Linux 服务器的用户。
> 示例服务器地址统一使用：
>
> ```bash
> qicheng@222.29.51.93
> ```

---

## 1. 登录和退出服务器

### 1.1 使用 SSH 登录服务器

在本机终端执行：

```bash
ssh qicheng@222.29.51.93
```

第一次连接时，可能看到：

```text
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

输入：

```text
yes
```

然后输入服务器密码。

注意：输入密码时，终端不会显示星号或其他字符，这是正常现象。

---

### 1.2 指定 SSH 端口

默认 SSH 端口是 `22`。如果服务器使用其他端口，例如 `2222`：

```bash
ssh -p 2222 qicheng@222.29.51.93
```

---

### 1.3 使用私钥登录

```bash
ssh -i ~/.ssh/id_rsa qicheng@222.29.51.93
```

如果私钥文件名不同，就替换为对应路径：

```bash
ssh -i ~/keys/server_key.pem qicheng@222.29.51.93
```

私钥权限过宽时，SSH 可能拒绝使用，可以执行：

```bash
chmod 600 ~/keys/server_key.pem
```

---

### 1.4 退出服务器

```bash
exit
```

也可以按：

```text
Ctrl + D
```

---

## 2. 认识命令行提示符

登录服务器后，可能看到：

```text
qicheng@server:~$
```

各部分含义：

* `qicheng`：当前用户名
* `server`：服务器名称
* `~`：当前位于用户主目录
* `$`：普通用户
* `#`：通常表示 root 用户

查看当前用户名：

```bash
whoami
```

查看当前服务器名称：

```bash
hostname
```

查看当前所在目录：

```bash
pwd
```

---

## 3. 查看和切换目录

### 3.1 查看当前目录

```bash
pwd
```

示例输出：

```text
/home/qicheng
```

---

### 3.2 查看目录内容

```bash
ls
```

显示详细信息：

```bash
ls -l
```

显示隐藏文件：

```bash
ls -a
```

同时显示详细信息和隐藏文件：

```bash
ls -la
```

以更易读的方式显示文件大小：

```bash
ls -lh
```

查看指定目录：

```bash
ls -lh /home/qicheng
```

---

### 3.3 切换目录

进入某个目录：

```bash
cd project
```

进入绝对路径：

```bash
cd /home/qicheng/project
```

返回上一级目录：

```bash
cd ..
```

返回用户主目录：

```bash
cd ~
```

或者直接：

```bash
cd
```

返回上一次所在目录：

```bash
cd -
```

进入根目录：

```bash
cd /
```

---

### 3.4 常见路径符号

| 符号   | 含义        |
| ---- | --------- |
| `/`  | Linux 根目录 |
| `~`  | 当前用户主目录   |
| `.`  | 当前目录      |
| `..` | 上一级目录     |
| `-`  | 上一次所在目录   |

## 5. 使用 nano 编辑文件

`nano` 是比较适合新手的终端文本编辑器。

### 5.1 打开或创建文件

```bash
nano notes.txt
```

编辑 Python 文件：

```bash
nano main.py
```

编辑配置文件：

```bash
nano config.yaml
```

文件不存在时，保存后会自动创建。

---

### 5.2 nano 常用快捷键

在 nano 底部：

```text
^O
```

其中 `^` 表示 `Ctrl`，所以 `^O` 就是 `Ctrl + O`。

| 快捷键        | 功能       |
| ---------- | -------- |
| `Ctrl + O` | 保存文件     |
| `Enter`    | 确认文件名    |
| `Ctrl + X` | 退出 nano  |
| `Ctrl + W` | 搜索文本     |
| `Ctrl + K` | 剪切当前行    |
| `Ctrl + U` | 粘贴       |
| `Ctrl + G` | 查看帮助     |
| `Ctrl + C` | 显示当前光标位置 |
| `Alt + U`  | 撤销       |
| `Alt + E`  | 重做       |

---

### 5.3 保存并退出 nano

1. 按 `Ctrl + O`
2. 按 `Enter` 确认文件名
3. 按 `Ctrl + X` 退出

如果文件修改后直接按 `Ctrl + X`，nano 会询问：

```text
Save modified buffer?
```

输入：

```text
Y
```

然后按 `Enter`。

---

### 5.4 没有安装 nano

检查 nano 是否存在：

```bash
nano --version
```

Ubuntu 或 Debian 系统安装：

```bash
sudo apt update
sudo apt install nano
```

CentOS、Rocky Linux 或 AlmaLinux 安装：

```bash
sudo dnf install nano
```

较旧的 CentOS 也可能使用：

```bash
sudo yum install nano
```

## 6. 查看文件内容

### 6.1 一次性显示整个文件


| `q`     | 退出      |

### 6.3 查看文件开头

默认查看前 10 行：

```bash

```

查看前 20 行：

```bash

```

### 6.4 查看文件末尾

默认查看最后 10 行：

```bash
tail notes.txt
```

查看最后 50 行：

```bash
tail -n 50 notes.txt
```

持续查看日志新增内容：

```bash
tail -f app.log
```

退出持续查看：

```text
Ctrl + C
```

## 7. 复制、移动和删除文件

### 7.1 复制文件

```bash
cp source.txt backup.txt
```

把文件复制到某个目录：

```bash
cp source.txt backup/
```

复制目录及其内部内容：

```bash
cp -r project project_backup
```

复制时显示执行过程：

```bash
cp -rv project project_backup
```

---

### 7.2 移动文件

```bash
mv source.txt data/
```

---

### 7.3 重命名文件

Linux 中，重命名也使用 `mv`：

```bash
mv old_name.txt new_name.txt
```

重命名目录：

```bash
mv old_project new_project
```

---

### 7.4 删除文件

```bash
rm test.txt
```

删除前询问：

```bash
rm -i test.txt
```

---

### 7.5 删除空目录

```bash
rmdir empty_directory
```

---

### 7.6 删除非空目录

```bash
rm -r project
```

强制递归删除：

```bash
rm -rf project
```

> **危险：** `rm` 删除的文件通常不会进入回收站。
>
> 使用 `rm -rf` 前，务必先通过下面的命令确认路径：
>
> ```bash
> pwd
> ls
> ls project
> ```
>
> 不要随意执行来源不明的 `rm -rf` 命令。

## 8. 本机和服务器之间传输文件：scp

`scp` 命令一般在**本机终端**执行，而不是登录服务器后再执行。

基本结构：

```bash
scp 本地路径 用户名@服务器地址:服务器路径
```

或者：

```bash
scp 用户名@服务器地址:服务器路径 本地路径
```

---

### 8.1 从本机上传文件到服务器

把本机当前目录的 `test.txt` 上传到服务器主目录：

```bash
scp test.txt qicheng@222.29.51.93:~
```

上传到服务器指定目录：

```bash
scp test.txt qicheng@222.29.51.93:/home/qicheng/project/
```

上传后修改文件名：

```bash
scp test.txt qicheng@222.29.51.93:/home/qicheng/project/server_test.txt
```

---

### 8.2 从服务器下载文件到本机

下载到本机当前目录：

```bash
scp qicheng@222.29.51.93:/home/qicheng/project/result.txt .
```

这里最后的 `.` 表示本机当前目录。

下载到本机指定目录：

```bash
scp qicheng@222.29.51.93:/home/qicheng/project/result.txt ~/Downloads/
```

---

### 8.3 上传整个目录

需要添加 `-r`：

```bash
scp -r local_project qicheng@222.29.51.93:/home/qicheng/
```

---

### 8.4 下载整个目录

```bash
scp -r qicheng@222.29.51.93:/home/qicheng/project .
```

---

### 8.5 指定 SSH 端口

注意：`scp` 指定端口使用大写 `-P`。

```bash
scp -P 2222 test.txt qicheng@222.29.51.93:~
```

SSH 登录则使用小写 `-p`：

```bash
ssh -p 2222 qicheng@222.29.51.93
```

---

### 8.6 使用 SSH 私钥传输

```bash
scp -i ~/.ssh/id_rsa test.txt qicheng@222.29.51.93:~
```

---

### 8.7 显示更详细的传输信息

```bash
scp -v test.txt qicheng@222.29.51.93:~
```

---

### 8.8 文件名包含空格

可以给路径加引号：

```bash
scp "my file.txt" qicheng@222.29.51.93:~
```

下载服务器上带空格的文件：

```bash
scp "qicheng@222.29.51.93:/home/qicheng/my file.txt" .
```

实际使用中，建议尽量避免在 Linux 文件名中使用空格。

---

## 9. 使用 rsync 传输大量文件

对于大目录、重复同步或断点续传，`rsync` 通常比 `scp` 更方便。

上传目录：

```bash
rsync -avh --progress local_project/ qicheng@222.29.51.93:/home/qicheng/project/
```

下载目录：

```bash
rsync -avh --progress qicheng@222.29.51.93:/home/qicheng/project/ ./project/
```

常见参数：

| 参数           | 含义                  |
| ------------ | ------------------- |
| `-a`         | 保留目录结构和大部分文件属性      |
| `-v`         | 显示详细信息              |
| `-h`         | 以易读形式显示大小           |
| `--progress` | 显示传输进度              |
| `-z`         | 传输时压缩数据             |
| `--delete`   | 删除目标中源目录不存在的文件，谨慎使用 |

注意目录末尾的 `/`：

```bash
rsync -avh source/ target/
```

表示复制 `source` 目录里面的内容。

```bash
rsync -avh source target/
```

表示把整个 `source` 目录复制到 `target` 中。

## 10. 查找文件和目录

### 10.1 按名称查找

在当前目录及其子目录中查找：

```bash
find . -name "notes.txt"
```

忽略大小写：

```bash
find . -iname "notes.txt"
```

查找所有 Python 文件：

```bash
find . -name "*.py"
```

只查找文件：

```bash
find . -type f -name "*.py"
```

只查找目录：

```bash
find . -type d -name "data"
```

从用户主目录开始查找：

```bash
find ~ -name "result.txt"
```

---

### 10.2 按文件大小查找

查找大于 1 GB 的文件：

```bash
find . -type f -size +1G
```

查找大于 100 MB 的文件：

```bash
find . -type f -size +100M
```

---

### 10.3 使用通配符

| 通配符     | 含义         |
| ------- | ---------- |
| `*`     | 匹配任意数量字符   |
| `?`     | 匹配一个字符     |
| `[abc]` | 匹配指定字符中的一个 |

例如，查看所有 `.txt` 文件：

```bash
ls *.txt
```

查看以 `data` 开头的文件：

```bash
ls data*
```

```bash
grep "error" app.log
```

忽略大小写：

```bash
grep -i "error" app.log
```

显示行号：

```bash
grep -n "error" app.log
```

```bash

```

忽略大小写并显示行号：

```bash
grep -rin "error" .
```

只显示匹配的文件名：

```bash
grep -rl "error" .
```

```bash
grep -E "error|warning" app.log
```

### 11.3 排除某些内容

显示不包含 `debug` 的行：

```bash
grep -v "debug" app.log
```

## 12. 压缩和解压文件

### 12.1 tar.gz 格式

压缩目录：

```bash
tar -czvf project.tar.gz project/
```

解压：

```bash
tar -xzvf project.tar.gz
```

解压到指定目录：

```bash
tar -xzvf project.tar.gz -C /home/qicheng/project/
```

只查看压缩包内容：

```bash
tar -tzvf project.tar.gz
```

参数含义：

| 参数  | 含义      |
| --- | ------- |
| `c` | 创建压缩包   |
| `x` | 解压      |
| `z` | 使用 gzip |
| `v` | 显示过程    |
| `f` | 指定文件名   |
| `t` | 查看压缩包内容 |

---

### 12.2 zip 格式

压缩文件：

```bash
zip files.zip a.txt b.txt
```

压缩目录：

```bash
zip -r project.zip project/
```

解压：

```bash
unzip project.zip
```

解压到指定目录：

```bash
unzip project.zip -d project/
```

查看压缩包内容：

```bash
unzip -l project.zip
```

---

### 12.3 gzip 格式

压缩单个文件：

```bash
gzip large_file.txt
```

会生成：

```text
large_file.txt.gz
```

解压：

```bash
gunzip large_file.txt.gz
```

保留原文件进行压缩：

```bash
gzip -k large_file.txt
```

## 13. 文件权限

使用下面的命令查看权限：

```bash
ls -l
```

示例：

```text
-rwxr-xr-- 1 qicheng users 1024 Aug 3 10:00 run.sh
```

权限分成三组：

```text
rwx r-x r--
```

分别表示：

1. 文件所有者权限
2. 文件所属组权限
3. 其他用户权限

权限字符：

| 字符  | 含义    |
| --- | ----- |
| `r` | 可读    |
| `w` | 可写    |
| `x` | 可执行   |
| `-` | 没有该权限 |

---

### 13.1 添加执行权限

```bash
chmod +x run.sh
```

执行脚本：

```bash
./run.sh
```

---

### 13.2 数字权限

数字含义：

| 数字  | 权限     |
| --- | ------ |
| `4` | 读      |
| `2` | 写      |
| `1` | 执行     |
| `7` | 读、写、执行 |
| `6` | 读、写    |
| `5` | 读、执行   |

常见设置：

```bash
chmod 755 run.sh
```

含义：

* 所有者：读、写、执行
* 同组用户：读、执行
* 其他用户：读、执行

普通文本文件常用：

```bash
chmod 644 notes.txt
```

私钥文件通常使用：

```bash
chmod 600 ~/.ssh/id_rsa
```

---

### 13.3 修改文件所有者

```bash
sudo chown qicheng file.txt
```

同时修改用户和用户组：

```bash
sudo chown qicheng:qicheng file.txt
```

递归修改目录：

```bash
sudo chown -R qicheng:qicheng project/
```

## 14. sudo 和管理员权限

以管理员权限执行命令：

```bash
sudo 命令
```

例如：

```bash
sudo apt update
```

切换到 root 用户：

```bash
sudo -i
```

退出 root：

```bash
exit
```

查看自己是否有 sudo 权限：

```bash
sudo -l
```

> 不要在不理解命令作用时随意添加 `sudo`。
> 管理员权限下执行错误命令，可能影响整个服务器。

## 15. 进程管理

### 15.1 查看当前进程

```bash
ps
```

查看所有进程：

```bash
ps aux
```

搜索指定进程：

```bash
ps aux | grep python
```

也可以使用：

```bash
pgrep -a python
```

---

### 15.2 实时查看进程

```bash
top
```

退出：

```text
q
```

如果安装了 `htop`：

```bash
htop
```

`htop` 的界面更直观。

---

### 15.3 结束进程

假设进程 PID 是 `12345`：

```bash
kill 12345
```

如果普通结束无效：

```bash
kill -9 12345
```

按名称结束进程：

```bash
pkill python
```

`kill -9` 会强制终止进程，进程没有机会进行清理操作，因此不要优先使用。

---

### 15.4 查看端口对应的进程

查看占用 `8000` 端口的进程：

```bash
lsof -i :8000
```

或者：

```bash
ss -lntp | grep 8000
```

## 16. 前台、后台和长时间任务

### 16.1 终止当前程序

```text
Ctrl + C
```

---

### 16.2 暂停当前程序

```text
Ctrl + Z
```

查看暂停和后台任务：

```bash
jobs
```

把任务恢复到前台：

```bash
fg
```

把任务放到后台：

```bash
bg
```

---

### 16.3 使用 & 在后台运行

```bash
python train.py &
```

但是退出 SSH 后，程序仍可能被终止。

---

### 16.4 使用 nohup

让程序在退出 SSH 后继续运行：

```bash
nohup python train.py > train.log 2>&1 &
```

含义：

* `nohup`：退出终端后继续运行
* `> train.log`：标准输出写入日志
* `2>&1`：错误输出也写入同一个日志
* `&`：在后台运行

查看日志：

```bash
tail -f train.log
```

查找进程：

```bash
ps aux | grep train.py
```

## 17. 使用 tmux 管理长时间任务

`tmux` 可以创建一个不会因 SSH 断开而消失的终端会话。

### 17.1 创建会话

```bash
tmux new -s work
```

在 tmux 中运行任务：

```bash
python train.py
```

---

### 17.2 暂时离开会话

先按：

```text
Ctrl + B
```

松开后，再按：

```text
D
```

这叫做 detach。任务仍会继续运行。

---

### 17.3 查看已有会话

```bash
tmux ls
```

---

### 17.4 重新进入会话

```bash
tmux attach -t work
```

简写：

```bash
tmux a -t work
```

---

### 17.5 结束会话

进入会话后执行：

```bash
exit
```

或者在外面执行：

```bash
tmux kill-session -t work
```

## 18. 查看磁盘和目录大小

### 18.1 查看磁盘空间

```bash
df -h
```

重点关注：

* `Size`：总容量
* `Used`：已使用
* `Avail`：可用空间
* `Use%`：使用比例
* `Mounted on`：挂载位置

---

### 18.2 查看目录大小

查看当前目录总大小：

```bash
du -sh .
```

查看指定目录大小：

```bash
du -sh project/
```

查看当前目录下各文件和子目录大小：

```bash
du -sh *
```

按大小排序：

```bash

```



### 21.5 同时显示并保存输出


---

### 21.6 连续执行命令

无论前一个命令是否成功，都执行后一个：

```bash

```

前一个命令成功后才执行后一个：

```bash
command1 && command2
```

前一个命令失败后才执行后一个：

```bash
command1 || command2
```

示例：

```bash
mkdir output && cd output
```

## 30. 新手建议

### 30.1 删除前先查看

不要直接运行：

```bash
rm -rf 某个目录
```

先运行：

```bash
pwd
ls -la
ls -la 某个目录
```

确认无误后再删除。

---

### 30.2 修改配置前先备份

```bash
cp config.yaml config.yaml.bak
```

带日期备份：

```bash
cp config.yaml config.yaml.$(date +%Y%m%d_%H%M%S).bak
```

---

### 30.3 运行长任务使用 tmux

不要只在普通 SSH 窗口中运行数小时的程序。网络断开时，任务可能终止。

推荐：

```bash
tmux new -s work
```

---

### 30.4 不要随意使用 sudo

先弄清命令作用，再决定是否需要管理员权限。

---

### 30.5 区分本机和服务器

登录服务器后执行的命令，操作的是服务器。

例如：

```bash
ssh qicheng@222.29.51.93
rm test.txt
```

删除的是服务器上的 `test.txt`。

而下面这条命令通常在本机执行：

```bash
scp test.txt qicheng@222.29.51.93:~
```

它会把本机的 `test.txt` 上传到服务器。

可以使用下面的命令帮助确认当前机器：

```bash
hostname
whoami
pwd
```
