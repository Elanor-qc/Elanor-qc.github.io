# Linux 服务器一页速查表

> 示例服务器：`username@example.xx`
> 示例主目录：`/home/username`

## 登录与退出

```bash
ssh username@example.xx              # 登录
ssh -p 2222 username@example.xx      # 指定端口
exit                                 # 退出
```

## 目录与文件

```bash
pwd                  # 当前目录
ls -lah              # 查看文件和隐藏文件
cd 目录名             # 进入目录
cd ..                # 返回上一级
cd ~                 # 返回主目录
cd -                 # 返回上一次目录

mkdir project        # 创建目录
mkdir -p a/b/c       # 创建多级目录
touch file.txt       # 创建空文件

cp a.txt b.txt       # 复制文件
cp -r dir1 dir2      # 复制目录
mv old.txt new.txt   # 移动或重命名
rm file.txt          # 删除文件
rm -r directory      # 删除目录
```

> `rm` 删除后通常无法恢复，慎用 `rm -rf`。

## 编辑与查看文件

```bash
nano file.txt        # 打开或创建文件
cat file.txt         # 查看短文件
less file.txt        # 分页查看长文件
head -n 20 file.txt  # 查看前 20 行
tail -n 50 file.txt  # 查看后 50 行
tail -f app.log      # 实时查看日志
```

Nano 常用快捷键：

```text
Ctrl + O    保存
Enter       确认文件名
Ctrl + X    退出
Ctrl + W    搜索
```

## 本机与服务器传文件

以下命令通常在**本机终端**执行。

```bash
# 上传文件
scp file.txt username@example.xx:~

# 上传到指定目录
scp file.txt username@example.xx:/home/username/project/

# 下载文件
scp username@example.xx:/home/username/project/result.txt .

# 上传整个目录
scp -r local_project username@example.xx:/home/username/

# 下载整个目录
scp -r username@example.xx:/home/username/project .

# 指定 SSH 端口
scp -P 2222 file.txt username@example.xx:~
```

## 查找文件和内容

```bash
find . -name "file.txt"        # 按名称查找
find . -name "*.py"            # 查找 Python 文件
grep "error" app.log           # 搜索关键词
grep -rin "error" .            # 递归搜索并显示行号
```

## 压缩与解压

```bash
tar -czvf project.tar.gz project/   # 压缩
tar -xzvf project.tar.gz            # 解压
zip -r project.zip project/         # ZIP 压缩
unzip project.zip                   # ZIP 解压
```

## 权限

```bash
ls -l                 # 查看权限
chmod +x run.sh       # 添加执行权限
chmod 755 run.sh      # 脚本常用权限
chmod 644 file.txt    # 普通文件常用权限
chmod 600 key.pem     # 私钥常用权限
```

## 进程与后台任务

```bash
ps aux                     # 查看进程
ps aux | grep python       # 查找 Python 进程
top                        # 实时查看进程
kill PID                   # 结束进程
kill -9 PID                # 强制结束进程

nohup python main.py > run.log 2>&1 &
tail -f run.log
```

## tmux 长任务

```bash
tmux new -s work       # 创建会话
tmux ls                # 查看会话
tmux attach -t work    # 恢复会话
tmux kill-session -t work
```

临时离开 tmux：

```text
先按 Ctrl + B，松开后按 D
```

## 系统状态

```bash
df -h                  # 磁盘空间
du -sh *               # 文件和目录大小
free -h                # 内存
lscpu                   # CPU 信息
nproc                   # CPU 核心数
uname -a                # 系统信息
nvidia-smi              # NVIDIA GPU
```

## 网络与端口

```bash
ip a                         # 查看 IP
ping -c 4 example.com        # 测试网络
ss -lntp                     # 查看监听端口
lsof -i :8000                # 查看占用 8000 端口的进程
curl http://127.0.0.1:8000   # 测试本机服务
```

## Python 常用命令

```bash
python3 --version
python3 main.py

python3 -m venv .venv
source .venv/bin/activate
deactivate

pip install numpy
pip install -r requirements.txt
pip freeze > requirements.txt
```

## 常用快捷键

| 快捷键        | 功能     |
| ---------- | ------ |
| `Ctrl + C` | 终止当前命令 |
| `Ctrl + D` | 退出终端   |
| `Ctrl + L` | 清屏     |
| `Ctrl + R` | 搜索历史命令 |
| `Tab`      | 自动补全   |
| `↑ / ↓`    | 查看历史命令 |

## 最常用流程

```bash
ssh username@example.xx
cd ~/project
ls -lah
nano main.py
python3 main.py
```

长任务：

```bash
tmux new -s work
python3 main.py
```

下载结果到本机：

```bash
scp -r username@example.xx:/home/username/project/output .
```
